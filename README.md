SQL & Relational Database Design Assignments

This repository contains practical SQL scripts, query assignments, and Entity Relationship Diagrams (ERD) created for database design and management coursework.

Repository Contents

* **`Complete_SQL_Assignment.sql`**: A comprehensive SQL script containing table creation statements (`CREATE TABLE`), sample data insertions (`INSERT INTO`), and all foundational and scenario-based query solutions for Part I and Part II (including Assignment 1, 2, and 3).
* **`Assignment4_ERD.png`**: The relational database Entity Relationship Diagram (ERD) for the **SalesDB** project (covering Customers, Products, Employees, and Orders).
* **`Assignment5_ERD.png`**: The relational database Entity Relationship Diagram (ERD) for the **University Course Registration System** (covering Students, Instructors, Courses, and Enrollments).

Tools & Technologies Used

* **MySQL Server & MySQL Workbench**: Used for database creation, running SQL queries, managing relations, and executing the "Reverse Engineer" feature to generate ERDs.
* **Git & GitHub**: Used for version control, repository management, and code documentation.
